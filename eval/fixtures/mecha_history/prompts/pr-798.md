# Builtin tools announce truncation after the text, and miscount what they cut

**Crate:** `mecha-core` (`src/tool/builtin.rs`)

## Problem

Dispatch keeps a result's start and spills the rest. `shell` and `http_fetch` put their truncation note at the end, where it is spilled, and its figures are wrong. Counts taken from decoded text run high, because each invalid byte decodes to three.

## Desired behaviour

Add a helper that turns raw bytes into lossy UTF-8 of at most `cap` bytes and returns the text plus the number of **raw** bytes it covers. It must never split a character. Each invalid sequence becomes one U+FFFD, but only if that fits; otherwise stop.

**`shell`**

- Count every byte each stream carried. Stderr gets whatever room stdout leaves.
- On a cut, put a notice *before* the body, followed by advice and a blank line:
  - No stderr: `[truncated: the command wrote N bytes, and only the first M are shown. This is not all of it`
  - With stderr: `[truncated: the command wrote A bytes to stdout (the first B shown) and C to stderr (the first D shown).`
- An exit-status line stays first, ahead of the notice.
- Output that wasn't cut is unchanged.

**`http_fetch`**

On a cut, the line after the status reads `[truncated: the body is SIZE, and only the first M are shown. This is not the whole response`. SIZE is one of:

- `N bytes`, when the whole body was read
- `N bytes by its Content-Length`, when the read stopped early and the server's length is at least that
- `more than N bytes`, otherwise

**`fs_read` inside a program**

- Size the notice's room using the path as displayed.
- If there's no room for any text, return an error containing `was not read`, without the path.

**`read_text_window`**

Takes a capacity hint: for whole-file reads, the size capped at `cap`, plus one; otherwise 0.

## Interface

`mecha_core::tool::builtin` (private):

```rust
fn lossy_prefix(raw: &[u8], cap: usize) -> (String, usize)
async fn read_text_window<R: tokio::io::AsyncBufRead + Unpin>(
    reader: &mut R, offset: u64, limit: Option<u64>, cap: usize, capacity: usize,
) -> std::io::Result<(String, Option<u64>)>
```
