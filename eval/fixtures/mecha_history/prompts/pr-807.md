# Code mode: let a program read files with `open()` through `fs_read`

**Crate:** `mecha-core` (`src/interpreter/monty.rs`, `src/interpreter/mod.rs`, `src/tool/code.rs`)

## Problem

The most common way a `code` program fails is by calling `open(path)` or `pathlib`'s `read_text`. Every OS call is refused today, including for a program that was given `fs_read` and could read the same file that way.

## Desired behaviour

The monty worker reports file access as OS-call events, which `monty.rs` already answers. When `fs_read` is among the program's externals, file reads should work as follows.

**Opening a file.** A text-mode open is accepted. That covers no mode, `'r'` given positionally, and `mode='r'`, with or without extra keywords such as `encoding=` or `newline=`.

**Reading it.** Every way of reading an opened file goes through an ordinary `fs_read` host call with a `path` keyword:

- `read`, `readline` and `readlines`
- iterating the file, or passing it to `csv`
- `pathlib`'s `read_text`

Because these are ordinary host calls, the guard, limits, taint, `external` and the trace all apply. A tool failure surfaces where the program reads.

**The path.** It is passed as written, quotes included. Monty roots paths at `/`, so strip one leading `/`.

**Refusals.**

- Write, append and binary modes raise `PermissionError`. The message contains `only to read its text` and lists the functions the program was given.
- Other OS calls are refused as before.
- `open` without `fs_read` is refused as before.

**Backstop.** A read that goes through `open` costs two suspensions. `COUNTED_HOST_LIMITS` must therefore equal sub-calls + 2 × tool reads + handle operations from `tool::code::defaults`.

**Description.** The text after "each returns its result as a str" becomes:

- with `fs_read`: `(fs_read(path=...) returns the file's text, and open(path) reads a file's text the same way, but cannot write; a read that fails raises a RuntimeError, not a FileNotFoundError)`
- without it: `(there is no open(): a program has no files)`

The rest of the sentence is unchanged. Also correct the modules listed as available: `csv`, `collections`, `itertools`, `math`, `datetime`, `decimal`, `pathlib`.
