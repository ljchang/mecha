# Halcyon

Halcyon is a scheduling assistant for research labs. It reconciles calendars
across institutions and flags conflicts before they reach a human.

## Status

Pre-alpha. The ingest path works; the reconciliation engine does not.

## Layout

- `src/` — the daemon
- `data/` — configuration and sample data
- `notes/` — meeting notes

## Contact

Maintained by the Computational Social Affective Neuroscience lab.
