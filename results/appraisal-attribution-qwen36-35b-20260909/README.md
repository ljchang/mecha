# Invalid attribution pilot — preserved evidence

**Stopped on 2026-09-09; excluded from efficacy comparisons.** The initial
runtime (`f4c40cbe`) recorded criterion diagnostics correctly but the ordinary
intervention miner also treated their generic harness text as an owner follow-up.
Passing training tasks therefore produced unsupported user-correction reflections.
The first mismatch reflection also confused a false threshold predicate with a
failed task criterion. No consolidation had run when the pilot was stopped.

The failure was identified from the first learning-stage logs and reflection
records. The process was stopped before changing any runtime or fixture; this
archive retains the registered conditions, native export, completed transcripts,
learning evidence and stage logs. These outcomes are not pooled into a new run.

The replacement is [the v2 pilot](../appraisal-attribution-v2-qwen36-35b-20260909/README.md),
with fresh homes and the same tasks, seeds, ordering and evidence gates. It fixes
the harness marker/voice filter and clarifies the distinction between an artifact
verdict and the context predicate. The regression was demonstrated failing on the
old behavior before the fix.
