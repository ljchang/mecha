# Resources from Eshin

Eshin shared three tools worth exploring.

## GROBID

**Machine learning for scientific document parsing.** GROBID (GeneRation Of BIbliographic Data) is an open-source library that parses raw scientific PDFs and extracts structured content — titles, authors, abstracts, references, sections — into TEI-encoded XML. It uses deep learning (RNNs, transformers) and CRFs for high-accuracy extraction. Deployable as a web service or CLI tool. Great for building pipelines that process academic literature, build digital libraries, or feed structured data into research tools.

## Fly.io

**Deploy full-stack apps globally in seconds.** Fly.io lets you run Docker containers as lightweight virtual machines (Fly Machines) across 35+ regions worldwide. Built on Firecracker microVMs, it boots in under a second and supports persistent storage, private networking, and built-in observability (Prometheus + Grafana). Ideal for edge computing, globally distributed apps, and serverless-style workloads without cold-start pain.

## exe.dev

**Persistent Linux VMs for developers and AI agents.** exe.dev provides quickly provisioned, always-on Linux virtual machines with persistent disks. Access via SSH or share through URLs. API-first design with flexible resource allocation (shared CPU/RAM across multiple VMs). Well-suited for development workspaces, AI agent infrastructure, and any project that needs reliable, long-lived compute that stays running and accessible.
